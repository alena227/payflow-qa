# BUG-010: На мобильном экране таблица истории шире экрана, суммы уходят за край

| Поле | Значение |
|---|---|
| Severity | major |
| Priority | medium |
| Компонент | web (мобильная вёрстка) |
| Окружение | PayFlow, сборка `BUGS=1`, commit `843abf7`+, Chromium (эмуляция мобильных) |
| Требование | REQ-UI-03 |
| Тесты | `tests/ui/test_mobile.py::test_mobile_history_amount_visible` (TC-058) |
| Статус | New |

## Предусловия
- Пользователь с хотя бы одной операцией в истории

## Шаги воспроизведения
1. Открыть сайт в мобильном разрешении (iPhone 13 / 390×844).
2. Войти, сделать перевод (например, 1234.56 ₽), прокрутить к блоку «История».

## Фактический результат
Таблица истории шире экрана: её правый край (колонки «Сумма» и «Комиссия») выходит за границу viewport. Автотест `is_in_viewport(history)` = False на 390, 412 и 360px.

## Ожидаемый результат
По REQ-UI-03 таблица истории помещается по ширине экрана, суммы и комиссии видны полностью без горизонтальной прокрутки.

## Влияние
Пользователь телефона не видит суммы и комиссии своих операций — ключевую информацию в финансовом приложении.

## Дополнительно
Воспроизводимость: всегда на мобильных ширинах. На `BUGS=0` таблица помещается в экран.
Связано с BUG-009 (общий корень — мобильная вёрстка), но проявляется на отдельном блоке; разделено, т.к. может чиниться независимо.
