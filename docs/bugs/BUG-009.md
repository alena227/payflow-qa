# BUG-009: На мобильном экране страница шире экрана — горизонтальная прокрутка, форма перевода обрезана

| Поле | Значение |
|---|---|
| Severity | major |
| Priority | high |
| Компонент | web (мобильная вёрстка) |
| Окружение | PayFlow, сборка `BUGS=1`, commit `843abf7`+, Chromium (эмуляция мобильных) |
| Требование | REQ-UI-03 |
| Тесты | `tests/ui/test_mobile.py::test_mobile_no_horizontal_scroll_and_button_visible` (TC-058) |
| Статус | New |

## Предусловия
- Войти в веб-клиент http://localhost:8090 под любым пользователем

## Шаги воспроизведения
1. Открыть сайт в мобильном разрешении (DevTools → Device Toolbar → iPhone 13 / 390×844, или Playwright).
2. Войти, посмотреть на страницу кабинета.

## Фактический результат
- Появляется горизонтальная прокрутка страницы: содержимое шире экрана.
- Замер: при ширине экрана 375px `document.documentElement.scrollWidth = 469px` (шире на 94px).
- Карточки «Счета», «Перевод» и правый край кнопки «Перевести» уходят за край экрана (см. скриншот).
- Воспроизводится на 390×844 (iPhone 13), 412×915 (Pixel 7) и 360×740.

![Горизонтальная прокрутка на мобильном](img/BUG-009-mobile-overflow.jpg)

## Ожидаемый результат
По REQ-UI-03 на ширине от 360px нет горизонтальной прокрутки страницы, все элементы формы перевода и кнопка «Перевести» видны целиком.

## Влияние
Часть банковских вакансий прямо требует мобильный веб. Пользователь телефона видит обрезанный интерфейс, часть кнопки «Перевести» может быть недоступна.

## Дополнительно
Воспроизводимость: всегда на мобильных ширинах. На `BUGS=0` страница помещается в экран (тест проходит).
