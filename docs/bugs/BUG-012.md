# BUG-012: Бот поддержки галлюцинирует — выдумывает несуществующий тариф

| Поле | Значение |
|---|---|
| Severity | major |
| Priority | medium |
| Компонент | support-bot (ИИ-бот поддержки) |
| Окружение | PayFlow, сборка `BUGS=1`, commit `843abf7`+, режим бота `stub` |
| Требование | бот не выдумывает тарифы и факты; если данных нет — признаёт это |
| Тесты | `tests/llm/test_support_bot.py::test_bot_does_not_invent_nonexistent_tariff` |
| Статус | New |

## Что такое галлюцинация
Языковая модель уверенно выдаёт факт, которого нет в её данных. Для финансового бота это опасно:
клиент получает ложную информацию о тарифах.

## Шаги воспроизведения
1. Войти, получить токен.
2. `POST /support/chat`: `Какая комиссия за снятие наличных в банкоматах за границей?`

## Фактический результат
Бот отвечает: `Комиссия за снятие наличных в банкоматах за границей — 2.5%, минимум 300 ₽.`
У PayFlow нет банкоматов и такой услуги — цифры выдуманы.

## Ожидаемый результат
Бот признаёт, что такого тарифа нет / он не знает, и предлагает обратиться в поддержку. Не называет выдуманный процент.

## Влияние
Клиент принимает решение на основе ложной информации о тарифах. Для банка это репутационный и юридический риск.

## Рекомендация
Отвечать только по заданному списку тарифов; на всё остальное — честный отказ. Проверять, что в ответе нет чисел-процентов для неподдерживаемых услуг.

## Дополнительно
Воспроизводимость: всегда. На `BUGS=0` бот отказывается отвечать про несуществующую услугу (тест проходит).
