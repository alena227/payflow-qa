# BUG-001: Комиссия за перевод округляется вниз вместо ROUND_HALF_UP

| Поле | Значение |
|---|---|
| Severity | critical |
| Priority | high |
| Компонент | api (расчет комиссии) |
| Окружение | PayFlow, сборка `BUGS=1`, commit `c0db431`, Windows 11, Docker Desktop, Swagger UI |
| Требование | REQ-TRF-03 |
| Тест-кейсы | TC-020, TC-022, TC-023, TC-025 (следствие), TC-057 (UI) |
| Автотесты | `tests/api/test_transfer_fee.py`, `tests/ui/test_web_e2e.py::test_transfer_updates_balance_and_history` (комиссия 12.34 вместо 12.35 видна и в веб-интерфейсе) |
| Статус | New |

## Предусловия
- `.\infra\reset.ps1`
- Получен токен alice@example.com (`POST /auth/login`)

## Шаги воспроизведения
1. `POST /transfers` `{"from_account_id": 3, "to_account_id": 5, "amount": "1250.50"}`
2. Посмотреть поле `fee` в ответе.

## Фактический результат
`"fee": "12.50"`

## Ожидаемый результат
`"fee": "12.51"`: 1% от 1250.50 = 12.505, по REQ-TRF-03 округление ROUND_HALF_UP до 0.01, значит, половина округляется вверх.

## Примеры (все воспроизводятся)

| Счет | Сумма | 1% / граница комиссии | Ожидается | Факт | |
|---|---|---|---|---|---|
| RUB | 49 999.99 | 499.9999 | 500.00 | 499.99 | ✗ |
| RUB | 1 234.56 | 12.3456 | 12.35 | 12.34 | ✗ |
| RUB | 1 250.50 | 12.505 | 12.51 | 12.50 | ✗ |
| RUB | 1 234.40 | 12.344 | 12.34 | 12.34 | ✓ |
| USD | 10.00 | мин. 10 ₽ / 92.475 = 0.10814 | 0.11 | 0.10 | ✗ |
| USD | 100.00 | 92.475 ₽ / 92.475 = 1.00000 | 1.00 | 1.00 | ✓ |
| USD | 700.00 | макс. 500 ₽ / 92.475 = 5.4069 | 5.41 | 5.40 | ✗ |

**Закономерность:** все знаки после второго отбрасываются (по сути ROUND_DOWN). Кейсы, где по правилам округлять нужно вниз или нечего округлять, проходят. Границы мин./макс. (10 ₽ / 500 ₽) применяются верно, ошибка только в финальном округлении. Проявляется для RUB- и USD-счетов, то есть, вероятно, в общей функции расчета комиссии.

## Следствия
- TC-025: баланс alice после перевода 10 USD равен 989.90 вместо 989.89 (списана комиссия 0.10 вместо 0.11).
- Компания систематически недополучает до 0.01 с каждого перевода; на большом объеме это заметная сумма, и сверки с бухгалтерией не сойдутся.

## Вложения
- Ответы `POST /transfers` из прогона Qase «Manual run 1 — BUGS=1» (TC-020, TC-022, TC-023).

## Дополнительно
Воспроизводимость: всегда. Обходного пути нет.
