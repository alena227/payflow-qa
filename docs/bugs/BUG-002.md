# BUG-002: Перевод на сумму, равную суточному лимиту (300 000 ₽), отклоняется

| Поле | Значение |
|---|---|
| Severity | major |
| Priority | high |
| Компонент | api (проверка суточного лимита) |
| Окружение | PayFlow, сборка `BUGS=1`, commit `c0db431`, Windows 11, Docker Desktop, Swagger UI |
| Требование | REQ-TRF-05 |
| Тест-кейс | TC-029 |
| Статус | New |

## Предусловия
- `.\infra\reset.ps1`: переводов за текущие сутки нет
- Получен токен alice@example.com

## Шаги воспроизведения
1. `POST /accounts/3/topup` `{"amount": "300000"}` → 201, баланс RUB 400 000.00
2. `POST /transfers` `{"from_account_id": 3, "to_account_id": 5, "amount": "300000.00"}`

## Фактический результат
`422 {"detail": "daily transfer limit exceeded"}`. Воспроизведено дважды, второй раз сразу после сброса стенда (первый перевод за сутки).

## Ожидаемый результат
`201`. По REQ-TRF-05 отклоняется перевод, после которого сумма за сутки станет **больше** 300 000 ₽; «ровно 300 000 — разрешено».

## Анализ
Граница сдвинута: условие, судя по поведению, реализовано как `>=` вместо `>`. Перевод на 300 000.00 при нулевых расходах за день отклоняется, хотя средств достаточно (нужно 300 500 с комиссией, на счете 400 000).

Проверить соседнее значение 299 999.99: если оно проходит, граница сдвинута ровно на 0.01.

## Влияние
Клиент не может перевести разрешенную сумму, обходного пути нет (кроме дробления на суммы меньше лимита).

## Следствия для прогона
TC-029 шаг 3 (перевод 0.01 после 300 000) заблокирован этим дефектом.

## Дополнительно
Воспроизводимость: всегда.
