# Чек-лист безопасности API

Отмечай `[x]` по мере проверки, для проблем — ссылка на баг-репорт. Детальные шаги — в тест-кейсах (TC-0xx) и в отчете дня 7.

## Аутентификация и JWT
- [ ] Без токена → 401 на всех защищенных эндпоинтах (обойти все из Swagger)
- [ ] Битый / обрезанный токен → 401
- [ ] Токен с измененным payload (sub) без переподписи → 401
- [ ] Токен, подписанный другим секретом → 401
- [ ] `alg: none` → 401
- [ ] `alg: HS512` / `RS256` (подмена алгоритма) → 401
- [ ] Истекший токен (exp в прошлом) → 401
- [ ] Токен без exp / без sub → 401
- [ ] Токен удаленного/несуществующего пользователя (sub = 99999) → 401
- [ ] Токен системного пользователя (sub = 1) не дает доступ
- [ ] Время жизни токена = 30 минут

## Пароли и перебор
- [ ] Одинаковый ответ для «нет такого email» и «неверный пароль»
- [ ] Время ответа для существующего и несуществующего email не отличается заметно (timing)
- [ ] Блокировка после 5 неудач → 429, через 5 минут снимается
- [ ] Блокировку нельзя обойти сменой регистра email (`ALICE@example.com`)
- [ ] Пароль не возвращается ни в одном ответе и не пишется в логи
- [ ] В БД только bcrypt-хэш (`$2b$...`)

## 2FA
- [ ] Без otp → 401 otp required
- [ ] Неверный / пустой / null / нечисловой / 7-значный otp → 401
- [ ] Старый код (2+ окна назад) не принимается
- [ ] Перебор otp упирается в блокировку входа
- [ ] Отключение 2FA требует верный код
- [ ] Секрет 2FA не возвращается нигде, кроме ответа setup

## Авторизация (IDOR)
- [ ] `GET /accounts/{id}` чужого счета
- [ ] `POST /accounts/{id}/topup` на чужой счет
- [ ] `POST /transfers` с чужого `from_account_id`
- [ ] Перевод на системный счет комиссий
- [ ] `/transactions` и `/notifications` возвращают только свои записи
- [ ] Перебор id счетов не раскрывает, какие существуют (одинаковый 404)

## Входные данные
- [ ] Отрицательные, нулевые, огромные суммы, 3+ знака после запятой, экспонента (`1e3`), строка, null
- [ ] SQL-инъекции в email (`' OR 1=1--`) и в параметрах пути/запроса
- [ ] XSS в email при регистрации → отображается ли как текст в UI
- [ ] Лишние поля в JSON игнорируются (mass assignment: `balance`, `user_id`, `is_system`)
- [ ] Очень большое тело запроса

## CORS и заголовки
- [ ] Чужой Origin → нет `Access-Control-Allow-Origin`
- [ ] Preflight с чужим Origin не разрешен
- [ ] `Access-Control-Allow-Credentials` не сочетается с `*` / отраженным Origin
- [ ] Ошибки не раскрывают стектрейс, SQL, версии

## Бизнес-логика
- [ ] Гонка: параллельные переводы не уводят баланс в минус и не обходят лимит
- [ ] Лимит нельзя обойти переводами с разных счетов / в разных валютах
- [ ] Округление нельзя использовать для «бесплатных» переводов (комиссия всегда ≥ мин.)
- [ ] Перевод 0.01 RUB на USD-счет: что зачисляется, не теряются ли деньги

## Инструменты
- Burp Suite Community: Proxy + Repeater (подмена токена, id), Intruder (перебор паролей/otp — медленно в Community)
- jwt.io — декодирование и сборка токенов
- curl / Postman
